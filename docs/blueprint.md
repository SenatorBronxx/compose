# **App Name**: ERITAS Smart Transit

## Core Features:

- Landing Page with Key Information: Display ERITAS's logo, headline text, and CTA buttons. Feature highlights will give a quick understanding of ERITAS, and the 'How it Works' section guides users to grasp how the system functions.
- Pilot Program Page for University Students: Detail the pilot program, who is the target users and routes. A timeline highlights each phase.
- Mobile App (Passenger & Driver): Feature overview for both passenger and driver app.
- Driver Recruitment with Onboarding: The website details the onboarding procedure for drivers, outlines the eligibility requirements, provides an FAQ section, and a link for applying to become a driver.
- About ERITAS Section: Introduce visitors to ERITAS by stating the company's mission and values.
- Contact and Social Media Hub: Enable potential users to reach ERITAS by providing contact details, an interest submission form, and social media links.
- System Performance Reporting: Capture anonymous telemetry of website traffic. Display captured data on dashboard, visualize fleet management, payment transactions, and user stats for admins.

## Style Guidelines:

- Primary color: Vibrant green (#69B46F), symbolizing growth and efficiency.
- Background color: Dark grey (#2B2D2F), for a professional and modern feel. 
- Accent color: Blue-green (#5F9EA0) to create visual interest and align to trust.
- Font pairing: 'Space Grotesk' (sans-serif) for headers paired with 'Inter' (sans-serif) for body text.
- Use flat style icons for features and navigation. Icons related to transportation, mobility, and technology.
- Card-based layouts with rounded corners and subtle shadows to enhance the modern UI.
- Smooth transitions and subtle animations for a polished user experience. Hover effects on cards and buttons.
